日向翔阳 · 黄色雨衣桌宠动作预览 V4

本次预览：
idle：3.2 秒，呼吸、眨眼、睁眼/笑口切换、眉毛鼻子轻动、发梢轻摇。
hop：2.4 秒，屈膝蓄力、抓着衣角上提、腾空收腿、落地缓冲。
happy_bounce：2.4 秒，连续两次蹦跳，抓衣角、眯眼笑、头发回弹。

手指与衣角共享抓握顶点，袖子和手保持连续。
裸腿按大腿/小腿弯曲，整只雨靴固定在脚部骨骼上。
靴口具有实心内衬、隐藏小腿重叠和连续前沿覆盖。
左右眼、眉毛、鼻子、嘴和脸颊有独立骨骼，眨眼/笑口使用附件切换。
头发有根部与左右发束骨骼，起跳和落地时增加摆动及回弹。

查看：
双击 preview.html，可离线打开。也可使用已开启的本地预览服务。
近看菜单可选择表情与头发、手指与衣角、腿与靴口。
支持 0.5 倍慢放、暂停、拖动时间轴、原始姿势及显示骨骼。
GIF/WebP 由 Spine 4.2 官方运行时实际渲染帧编码。

交付格式：
hinata-raincoat.json：标准 Spine 4.2 骨骼、网格、骨骼动画和网格形变关键帧。
hinata-raincoat.atlas / hinata-atlas-1.png：实际运行的纹理图集。
images/：JSON 所引用的33个附件原图，包括闭眼和闭口替换图。
original-layers/：47个原始拆分图层，逐文件哈希检查确认未改变。
reference-approved.png / source-layers.json：原始确认形象及图层坐标。
art/ / prompt-set.json：内置 ImageGen 局部补绘与表情生成记录。

Spine 导入：
使用支持 4.2 的 Spine 编辑器，Import Data 导入 hinata-raincoat.json。
图片路径为 ./images/，可加载图集用于运行时。
骨骼、网格权重、附件切换和关键帧均可继续编辑。
小腿的体积校正烘焙为标准网格形变关键帧。

验证与限制：
已验证 Spine 4.2 官方 WebGL 运行时加载、三段动画循环、抓握接触、
落地脚部位置、雨靴形状保持、五官骨骼变化、头发摆幅和预览控件。
另检查了240帧的透明轮廓连通性以及隐藏小腿后的靴口内部。
这些检查不能替代人工审美判断；此版本先供动作和画面复核。
当前环境没有 Spine 编辑器，因此尚未在编辑器中执行导入验证。
本包是 JSON/atlas/PNG，不含原生 .spine 工程文件。
目前仅制作正面动作，尚未制作转身和正式 Windows 桌宠应用。
